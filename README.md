
# Garvit Maheshwari — Developer Portfolio

A responsive, multi-page personal portfolio website built
to showcase my technical skills, professional experience,
education, achievements, and software development journey.

Developed as part of the WeIntern Web Development
Internship — Week 1, Task 1.

## About Me

I'm Garvit Maheshwari, a Computer Science undergraduate
at the University of Petroleum and Energy Studies (UPES),
Dehradun, with an interest in backend engineering,
web development, database systems, and AI-assisted workflows.

## Features

- Responsive four-page website
- Professional dark-themed interface
- Desktop and mobile navigation
- Interactive technical skills filtering
- Dynamic professional experience switcher
- Project showcase placeholder for upcoming work
- Education, achievements, and certifications
- Contact form with prefilled email functionality
- GitHub and LinkedIn integration
- Downloadable resume
- Hover effects and responsive layouts

## Running Locally

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use Live Server.
4. Navigate between Home, About, Projects, and Contact.

No additional dependencies or build tools are required.

## Contact Form

The contact form validates visitor inputs and opens
the visitor's configured email application with a
prefilled message.

The visitor must send the email manually.
No backend message delivery is currently implemented.
